# gui — графический интерфейс планшета

Интерфейс по эскизу «Схема графического интерфейса» для дисплея 800×480 на RA8875.
Касания модуль получает снаружи и сам с тачем не работает.

## Уровни

| Ур. | Где | Что делает | Вызывает |
|---|---|---|---|
| 0 | `firmware/ra8875` | драйвер: линии, прямоугольники, круги, текст | SPI |
| 1 | `firmware/gfx` | составные фигуры и значки, без состояния | `ra8875` |
| 2 | `gui/widgets` | элементы интерфейса по координатам и состоянию | `gfx` |
| 3 | `gui/screen` | раскладка по эскизу, отрисовка зон, попадание касаний | `widgets` |
| 4 | `gui/gui` | состояние, логика, API для приложения | `screen` |

Каждый уровень вызывает только нижние уровни. Приложению нужен только `gui.h`.

## Уровень 1: gfx

| Функция | Смысл |
|---|---|
| `gfx_init` | запуск дисплея |
| `gfx_fill`, `gfx_border`, `gfx_frame` | прямоугольник: залитый, контур, залитый с контуром |
| `gfx_dashed_rect` | пунктирная рамка |
| `gfx_line`, `gfx_circle` | линия; круг с заливкой и контуром |
| `gfx_text_in` | текст в прямоугольнике: обрезка по ширине, выравнивание, фон вокруг |
| `gfx_arrow` | стрелка-галочка ∧ < > ∨ |
| `gfx_icon_battery/bluetooth/joycon` | значки статус-бара |
| `gfx_logo` | заглушка логотипа МИЭТ |

## Уровень 2: widgets

| Функция | Смысл |
|---|---|
| `wg_status_bar`, `wg_clock`, `wg_label` | статус-бар, часы ЧЧ:ММ:СС, надпись |
| `wg_vehicle_panel` | панель изделия: название и краткая телеметрия, выбранная подсвечена |
| `wg_tab` | язычок «скрыть/показать панели» |
| `wg_text_box`, `wg_text_lines` | пунктирная рамка с текстом; обновление только текста |
| `wg_assign_list` | назначения 4 кнопок со стрелками (и стика) |
| `wg_round_button`, `wg_stick` | экранные кнопки и стики, нажатые темнее |
| `wg_joycons`, `wg_bluetooth`, `wg_battery` | значки состояния |
| `wg_icon_visible` | виден ли значок с учётом мигания |
| `wg_hit`, `wg_hit_circle` | попало ли касание в элемент |

## Уровень 3: screen

- `screen_model_t` — всё, что должно быть на экране.
- Раскладка зависит от двух флагов: панели скрыты или нет, подключены ли физические джойстики. Размеры взяты из эскиза в мм и пересчитаны в px, все константы собраны в начале `screen.c`.
- `screen_draw_all` рисует весь экран, `screen_draw_<зона>` — отдельную зону.
- `screen_hit` определяет, куда попало касание.

## Уровень 4: gui

| Функция | Смысл |
|---|---|
| `gui_init(vehicles)` | запуск; описания 3 изделий (название, назначения кнопок и стиков) |
| `gui_set_battery(0..5)` | заряд; при 0–1 делении значок красный |
| `gui_set_bluetooth` | нет / поиск (мигает) / подключён |
| `gui_set_joysticks(left, right)` | один подключён: он горит, второй мигает; оба: экранное управление убирается |
| `gui_set_telemetry(i, summary, details)` | краткая (на панели) и подробная (строки через `\n`) |
| `gui_set_message` | сообщение об ошибке в статус-баре |
| `gui_select`, `gui_toggle_panels` | выбрать изделие; скрыть или показать панели |
| `gui_touch(x, y, pressed)` | касание: панель выбирает изделие, язычок скрывает панели, кнопки подсвечиваются |
| `gui_pressed` | какая экранная кнопка или стик удерживается |
| `gui_tick(ms)` | вызывать раз в 10–50 мс: часы, мигание, перерисовка |

Как работает обновление экрана:
- Сеттеры только запоминают данные и помечают зону, которую надо перерисовать. `gui_tick` перерисовывает только помеченные зоны.
- Текст рисуется вместе с заливкой фона вокруг себя, поэтому обновление не мерцает.

```c
gui_init(vehicles);
while (1)
{
    gui_set_telemetry(0, "U 7.4 V", "Battery: 7.4 V\nSpeed: 12 cm/s");
    gui_touch(x, y, pressed);
    gui_tick(HAL_GetTick());
    HAL_Delay(20);
}
```

## Тест

`test/test_gui` — демо с выдуманными данными:
- заряд убывает;
- Bluetooth и джойконы по очереди меняют состояние;
- телеметрия обновляется.

Работает и касание. Если оно не совпадает с картинкой, поменяй оси макросами `TOUCH_*` в `main.c`.

```bash
make top=test_gui
```

## Ограничения

- Встроенный шрифт RA8875 — только латиница. Для кириллицы нужен свой шрифт, менять придётся только `gfx_text_in`.
- Значки нарисованы примитивами, логотип пока заглушка.
- Анимации сдвига нет, раскладка переключается сразу.
- Касание одно: драйвер GSL1680 отдаёт одну точку.
- Проверено: сборка без предупреждений, раскладка — на ПК через заглушку драйвера. На железе не проверялось.
